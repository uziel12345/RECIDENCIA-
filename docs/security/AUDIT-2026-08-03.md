# Auditoría de seguridad — 2026-08-03

## Resumen ejecutivo

La revisión local encontró cuatro superficies de alto impacto en código: acceso público a horarios por matrícula, expansión no acotada de XLSX, validación insuficiente de imágenes y URLs almacenadas con esquemas ejecutables. Todas tienen corrección y prueba local. También se endurecieron JWT, contraseñas, errores de login, timeouts, CORS, logs, dependencias y CI.

No se hizo pentest, carga, DAST ni modificación de producción durante esta fase. Por tanto, “corregido” en esta tabla significa **corregido y verificado en el workspace, pendiente de un despliegue aprobado**. Los controles externos (MFA, WAF/CDN, copia offsite y cierre de SSH por contraseña) siguen pendientes.

## Alcance e inventario

- Monorepo pnpm: React/Vite/Three.js (`apps/web`), Express/PostgreSQL (`apps/api`) y tipos/clientes compartidos (`packages/shared`).
- Persistencia: PostgreSQL mediante `pg`; consultas revisadas usan parámetros y las partes dinámicas observadas provienen de listas internas.
- Autenticación: cookie JWT `httpOnly`, CSRF Double Submit, roles consultados en BD.
- Archivos: imágenes de edificios en disco y XLSX de horarios en memoria.
- Entrega: Nginx, systemd, Tailscale/Funnel, backup systemd y GitHub Actions versionados.
- Revisión de secretos: archivos rastreados y diff/historial mediante patrones; solo se identificaron placeholders de `.env.example`. Es una revisión heurística, no sustituye GitHub Secret Scanning.
