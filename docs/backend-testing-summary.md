# Resumen de pruebas backend

## Objetivo

Esta etapa tuvo como objetivo mejorar la calidad del backend agregando pruebas automáticas con Vitest, sin depender de una base de datos MySQL real.

Las pruebas se enfocan en validar reglas de negocio, controladores, repositorios, middlewares y utilidades críticas del sistema.

pnpm --filter api test
